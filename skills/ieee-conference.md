Review as an IEEE conference program committee member would.

1. **Problem & motivation** - Clear, practically relevant problem; contributions listed in the introduction.
2. **Technical approach** - Sound and described in enough detail; design choices justified.
3. **Evaluation** - Appropriate setup, metrics and comparison with existing methods; results discussed, not only reported.
4. **Related work** - Covers the main recent work and explains differences.
5. **Presentation** - IEEEtran conventions (abstract, index terms, numbered references in IEEE style), readable figures in two-column layout, page limit.
6. **Writing quality** - Grammar, consistent terminology, defined acronyms.
